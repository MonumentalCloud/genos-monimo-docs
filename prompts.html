    프롬프트 편집

    모니모 Agent의 프롬프트 탭은 작성한 지침, 백엔드가 조합하는 실행 지침, 실제 API 도구 설명을 나누어 편집합니다. 문구 편집과 엔진의 검증·도구 권한 변경은 별개입니다.

    기본 모드와 고급 모드

    기본 모드는 기존 자동 조합을 사용합니다. 고급 프롬프트 구성은 공통 블록과 단계별 목록을 편집합니다. 단계별 목록이 있으면 공통 목록을 대체하므로 공통에서 지운 문구가 resume나 afterTools에 남아 있지 않은지 확인하세요. 저장된 워크플로우가 실제 실행하는 입력입니다.

    지원 단계와 블록

    단계는 initial·afterTools·correction·resume·final·summarize·compress·structuredOutput입니다. 블록마다 고유 id·title, 필요한 role·text 또는 source를 둡니다. 단계당 최대 32블록이며 텍스트는 최대 65,536자입니다. source는 configuredInstructions·instructions·history·context·input·toolExchange입니다.

    일반 단계는 history·input·toolExchange를 각각 정확히 한 번 포함해야 하며 보호 그룹을 조건부로 숨길 수 없습니다. 보조 요약·압축·구조화 단계는 별도 구성을 따릅니다. when 조건과 part는 엔진이 지원하는 값만 사용하며 알 수 없는 단계·변수는 PROMPT_LAYOUT_INVALID입니다.

    그 밖에 instructions·context·input·memory·response·correction 변수도 지원합니다. 실행 변수는 모델 호출마다 결정합니다. 설정한 지침에 자동 엔진 지침 전체가 숨어 있다고 가정하지 말고 각 블록과 실제 모델 요청을 확인하세요.

    내부 도구 설명 편집

    declare_skills·declare_fallback·slot_fill·request_user_input·call_native_bridge·표 도구, 지식 검색과 A2A handoff 등의 설명을 편집합니다. 편집하지 않은 도구는 기본 설명을 유지합니다. 지원되는 템플릿 변수만 사용하며 도구 스키마와 권한·서버 처리기는 그대로입니다. slot_fill 설명 칸에 genos-slots 절차 본문을 넣지 않습니다.

    Vault 안내는 메시지 블록과 도구 description 사본 모두에 영향을 줄 수 있습니다. 메시지 미리보기만 보지 말고 모델 요청의 tools를 함께 확인합니다. $runtime.tools는 자기 문구가 재귀 포함되지 않도록 안내 추가 전 기본 도구 정의를 참조합니다.

    실제 요청 확인과 메모리 표시

    실행 상세의 모델 요청에서 메시지·도구·단계별 블록 포함 판정을 확인합니다. 상위 노드 Input과 실제 provider에 전달된 API 요청은 다를 수 있습니다. 장기 recall 본문은 실행 상세에서 생략될 수 있고 모델 관측의 보호 로그에서 확인합니다. 화면에서 안 보인다는 이유로 모델에도 전달되지 않았다고 판단하지 마세요.

    문구를 삭제해도 스킬·슬롯 검증, Vault 복원·만료, 체인 실행, qvo 계약, 오류·사용자 응답 전달은 유지됩니다. 프롬프트 편집은 실행 권한을 푸는 기능이 아닙니다.
