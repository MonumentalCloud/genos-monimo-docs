    운영과 호환성

    아래 항목은 호환성에 영향을 주는 현재 동작입니다. 이 차이에 맞춰 플로우를 설계하라는 뜻은 아닙니다.

    항목 작성 의도 또는 기대 규칙 현재 구현
    한 체인 분기에 stop:true와 tool 함께 지정 이 조합을 작성하지 않음. 들어오면 즉시 중단 파서가 허용하고 runChain이 지정 도구와 후속 체인을 실행할 수 있음. 중단·도구 분기를 분리해야 함
    슬롯 number 작성자의 용도에 맞는 숫자 처리 단일 값은 음수 아닌 정수 금액으로 제한
    검증 인자 상수 작성자가 정한 제약을 유지 성공한 검증 호출의 고정값이 선언과 달라도 통과 가능
    문구 없는 네이티브 브릿지 의도한 빈 프롬프트 유지 마스터 위임 경로에서 기본 안내 문구로 대체될 수 있음
    이전 confirm 문자열 확인은 boolean 결정 일부 호환 경로가 문자열 boolean을 허용하며, 텍스트와 구조화된 A2A 결정 변환이 다를 수 있음

    stop과 tool의 규칙은 이 가이드를 작성하면서 Marvin이 확인했습니다. 나머지는 현재 기본 동작 리뷰에 기록된 차이이며, 호환성을 유지하는 동안 알아두어야 할 항목입니다. 이 문서는 실행 동작을 변경하지 않습니다.

    버전과 검증 범위

    아직 반영되지 않은 Vault 후속 PR #23511에는 원시 타입 정의, 인라인 중첩, 수명·개인정보 처리 수정이 포함됩니다. 해당 스키마를 이 가이드의 기준 버전에 그대로 복사하면 안 됩니다. 기준 버전의 정의 검증기는 valueType과 인라인 필드 정의를 거절합니다. 브랜치 병합과 배포 이미지 교체도 별개입니다.

    실제 플로우에서는 배포된 정확한 버전을 확인하고, 에이전트의 도구 호출부터 사용자에게 보이는 결과까지 전체 경로를 점검하세요. 승인·거절·알 수 없는 ID·취소·검증 실패·재시도·체크포인트 재개를 포함해야 합니다. 실제 후속 인자와 최종 업무 결과를 확인하고, 뒤 단계가 실패해도 완료된 작업을 반복하지 않는지 보세요. Vault는 사용할 수 없는 참조, 표시 복원, 이후 대화 이력까지 확인하세요.

    이 인터랙티브 데모는 기능 규칙을 설명합니다. 해당 배포 환경의 실제 모델 동작, 네이티브 GenPortal 브라우저 동작, 프로덕션 빌드 성공, 운영 추적 데이터 저장을 검증한 것은 아닙니다.

    반복 횟수와 공개 오류 안내

    Max Iterations는 도구 호출과 필수 스킬 결정 재시도의 라운드 한도입니다. 미설정·0은 무제한입니다. 처리 단계 한도 안내 문구는 앞뒤 공백 제거 후 최대 2,000자이며 비면 기본 안내를 씁니다. AGENT_ITERATION_LIMIT 실패를 유지하고 검증된 publicError의 code·message만 사용자·마스터에 전달합니다.

    한도에서 유효한 HITL 카드가 있으면 먼저 카드를 표시하고 나머지는 응답까지 대기합니다. 취소·잘못된 응답에서는 대기 도구를 실행하지 않으며 재개 뒤 라운드는 기존 방식으로 새로 계산합니다. 일반 최종 답변·빈 답변·브릿지의 빈 대기 문구를 한도 안내로 바꾸지 않습니다. 기본 Agent와 genos-chain의 한도 정책은 별도입니다.

    저장과 큐와 실행 이력

    Flowise 서버의 agentflow runner, checkpoint, A2A 협력 실행, BullMQ 응답, 메시지 저장·표시 경로도 변경 범위입니다. 큐 작업이 completed인 것과 업무 워크플로우가 성공한 것은 다를 수 있습니다. 실패 봉투를 풀고 실제 실행 상태·최종 출력·메트릭을 확인해야 합니다.

    모델용 본문과 사용자 표시 본문은 구분해서 저장할 수 있습니다. Vault는 모델 이력에 발급 참조를 유지하고 사용자가 볼 때 복원하므로 이전 대화가 비어 보이는 문제를 단순 모델 생성 실패로 단정하지 마세요. 스키마 변경과 배포 이미지, 진행 중 checkpoint의 호환성을 함께 확인합니다.
